# TimeSeriesArticle

Пишем статью по временным рядам

## Идеи по датасетам

- акции и продажи европейских и китайских транспортных средств на территории РФ
- Nike и Puma, после подписи выгодных контрактов (посмотреть, насколько сильно поднялись акции)
- акции ии-шных компаний (OpenAI, Anthropik, ....) (лучше взять другие компании, которые их финансируют, типа NVDIA)
- Было бы классно взять датасеты с разной структурой (с сезонностью/без и например)

## Идеи по моделям

- ARIMA (SARIMA и другие вариации)
- MLP
- Рекурентные сети (LSTM, GRU)
- Градиентный бустинг
- Foundation Models

## Идеи по метрикам (как сравнивать будем)

- Базовые метрики прогнозирования
- Время обучения
- Время инференса
- Интерпретируемость
